The architecture starts with a user interacting with an Amazon API Gateway. The API Gateway receives two types of requests: /action_item and /summary. For /action_item requests, it invokes the Action Item Lambda function, which interacts with an Amazon Bedrock service. For /summary requests, it triggers the Summary Lambda function, which also interacts with the Amazon Bedrock service. The Lambda functions process the requests and responses, leveraging the Bedrock service for generative AI. The API Gateway acts as the entry point, routing requests to the appropriate Lambda functions, which handle the business logic and generate AI operations using the Bedrock service.
