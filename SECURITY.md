# Security Policy

The maintainers of `architecture-to-cloudformation-agents` take security seriously. We appreciate the efforts of security researchers and the community to responsibly disclose vulnerabilities so we can protect our users.

## Supported Versions

Only the **latest major release** of this project receives security updates. Older major versions are considered end-of-life and will not receive patches.

| Version       | Supported          |
| ------------- | ------------------ |
| Latest major  | :white_check_mark: |
| Older majors  | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.**

Instead, report them privately by emailing:

**security@example.com**

To help us triage and respond quickly, please include as much of the following information as you can:

- A clear description of the issue and its potential impact
- Steps to reproduce, including any proof-of-concept code, scripts, or screenshots
- The affected version, commit SHA, or deployment configuration
- Any known mitigations or workarounds

## Response Process

- **Acknowledgement:** We aim to acknowledge every report within **48 hours** of receipt.
- **Triage:** We will investigate the report, work with you to confirm the issue, and assess severity.
- **Remediation:** We will develop, test, and release a fix for supported versions.
- **Coordination:** We will coordinate disclosure timing with you and credit reporters who wish to be acknowledged.

## Coordinated Disclosure

We follow a **90-day coordinated disclosure** policy. Please refrain from publicly disclosing a reported vulnerability for **90 days** after your initial report, or until a fix has been released — whichever comes first — to give users time to upgrade.

If a vulnerability is being actively exploited in the wild, we may agree to an accelerated timeline.

## Scope

This policy applies to the code and assets in this repository. Vulnerabilities in upstream dependencies should be reported to their respective maintainers; please still let us know if a dependency issue affects this project.

Thank you for helping keep this project and its users safe.
