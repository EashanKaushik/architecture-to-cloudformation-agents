# Security Policy

## Reporting Security Vulnerabilities

We take the security of this project seriously. If you discover a security vulnerability, please follow our responsible disclosure policy.

### How to Report

**Do not create a public GitHub issue for security vulnerabilities.**

Instead, please report security issues to:
- **Email:** security@example.com

### What to Include

Please provide the following information in your report:
- Description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Any suggested fixes (optional)

### Response Time

We aim to acknowledge receipt of vulnerability reports within **48 hours**. We will work with you to understand and address the issue promptly.

## Supported Versions

We provide security updates for the latest major version only. Please ensure you are using the most recent release before reporting issues.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < Latest| :x:                |

## Disclosure Policy

We request that security researchers:
- Provide us with a reasonable amount of time to address the vulnerability before public disclosure
- Wait at least **90 days** after reporting before making any public disclosure
- Make a good faith effort to avoid privacy violations, data destruction, or service interruption

We commit to:
- Acknowledging your report within 48 hours
- Providing regular updates on our progress
- Crediting you for the discovery (unless you prefer to remain anonymous)
- Working with you on a coordinated disclosure timeline

Thank you for helping keep this project and its users safe.
